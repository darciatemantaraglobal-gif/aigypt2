### Layout Foto — Masonry Grid Dinamis

Tampilkan kelima foto dalam layout masonry (bukan grid seragam) agar terasa lebih organik seperti feed nyata, bukan presentasi korporat.

Desktop (5 kolom adaptif, 2 baris):
```
[ Foto 1 — landscape lebar  ] [ Foto 2 — portrait         ]
[ Foto 3 — landscape lebar  ] [ Foto 4 — landscape lebar  ] [ Foto 5 — portrait kecil ]
```

Atau gunakan CSS columns untuk masonry yang lebih mudah diimplementasi:

```css
.gallery-grid {
  columns: 3;
  column-gap: 12px;
}

.gallery-item {
  break-inside: avoid;
  margin-bottom: 12px;
  border-radius: 12px;
  overflow: hidden;
  position: relative;
}

/* Tablet: 2 kolom */
@media (max-width: 768px) {
  .gallery-grid { columns: 2; }
}

/* Mobile: 1 kolom */
@media (max-width: 480px) {
  .gallery-grid { columns: 1; }
}
```

## LANGKAH 4 — Optimasi Gambar

Karena foto-foto ini adalah file JPEG berukuran besar (kemungkinan beberapa MB per foto), lakukan optimasi dasar:

1. Jika ada tooling (sharp, imagemin, atau sejenisnya tersedia di environment), kompres foto ke kualitas 80% JPEG tanpa mengubah dimensi
2. Tambahkan atribut `loading="lazy"` pada setiap tag `<img>` agar foto di bawah viewport tidak diload duluan
3. Tambahkan atribut `decoding="async"` untuk performa lebih baik
4. Set dimensi dengan `width` dan `height` yang sesuai untuk mencegah layout shift (CLS)

```tsx
<img
  src={photo.src}
  alt={photo.alt}
  loading="lazy"
  decoding="async"
  className="gallery-photo"
/>
```

## ANIMASI

Terapkan animasi yang konsisten dengan sistem yang sudah ada di lib/animations.ts:
- Header section (label, headline, sub): fadeRise
- Grid foto: stagger reveal, setiap foto muncul berurutan dengan delay sekitar 0.1 detik antar foto
- Counter stats: count-up animation + glowPop saat masuk viewport (gunakan pola yang sama dengan stat grid di section Keanggotaan)

---

## REQUIREMENTS TEKNIS

1. File foto disimpan ke folder assets/gallery/ atau public/gallery/ sesuai konvensi project
2. Data foto di file terpisah lib/galleryPhotos.ts agar mudah ditambah foto baru nanti
3. Lazy loading pada semua gambar
4. Layout masonry responsive: 3 kolom desktop, 2 kolom tablet, 1 kolom mobile
5. Hover effect halus pada setiap foto (scale + brightness)
6. Caption muncul saat hover dengan fade-in
7. Counter stats dengan count-up animation
8. Semua teks Bahasa Indonesia
9. npm run build harus sukses
