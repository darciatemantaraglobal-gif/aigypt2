## CATATAN PENTING

Kupon HIFEST26 TIDAK punya batas pemakaian per email (berbeda dari AIGYPT26). Karena sistem validasi saat ini mengecek tabel `coupon_usage` untuk mencegah pemakaian ganda per email, tambahkan field baru `multiUse: true` pada interface Coupon dan logic validasi:

```typescript
export interface Coupon {
  code: string
  discountAmount: number
  applicableTo: 'kelas' | 'mandiri' | 'all'
  validUntil: string
  description: string
  multiUse?: boolean  // jika true, bisa dipakai berkali-kali oleh email berbeda
}
```

Update fungsi `validateCoupon` dan API route `api/coupons/check.ts` agar melewati pengecekan `coupon_usage` jika `coupon.multiUse === true`:

```typescript
// Di api/coupons/check.ts
// Jika kupon multiUse, skip pengecekan riwayat pemakaian
if (coupon.multiUse) {
  return res.status(200).json({ valid: true })
}

// Jika bukan multiUse, cek apakah email sudah pernah pakai
const { data: existingUsage } = await supabase
  .from('coupon_usage')
  .select('id')
  .eq('coupon_code', code.toUpperCase())
  .eq('email', email.toLowerCase())
  .single()

if (existingUsage) {
  return res.status(200).json({
    valid: false,
    error: 'Kupon ini sudah pernah kamu gunakan'
  })
}
```

Dengan ini AIGYPT26 tetap 1x per email, sementara HIFEST26 bisa dipakai berkali-kali oleh siapapun selama belum kedaluwarsa.
