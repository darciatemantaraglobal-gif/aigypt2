- Tipe datanya (`SesiMateri`, `MateriStep`, dll.) ada di `artifacts/aigypt/src/lib/materiContent.ts`. Semua field yang saya pakai (content, bullets, quote, prompts, table, cards, bigIdea, matrix, flow, note, isCompletion) sudah ada di interface itu dan sudah dirender oleh player materi di `artifacts/aigypt/src/pages/materi/index.tsx`. Tidak ada perubahan tipe atau komponen yang dibutuhkan.
- Metadata kelas ada di `artifacts/aigypt/src/lib/classesData.ts` pada entry dengan `id: "vibe-coding"`.

## Tugas 1 — Sisipkan step & sesi baru ke `vibeCoding.ts`

Di bagian bawah prompt ini ada 5 blok kode berlabel BLOK A sampai BLOK E. Variabel pembungkus `const BLOK_..._SESI_...` hanya wadah agar rapi — **jangan salin const-nya**, salin objek-objek step di dalamnya, apa adanya, karakter demi karakter. Titik sisipnya:

1. **BLOK A** (1 step, id `vc2-5d`) → di array `steps` Sesi 2, sisipkan **setelah** objek step ber-id `"vc2-5c"` dan **sebelum** step `"vc2-6"`.
2. **BLOK B** (2 step, id `vc3-1a` dan `vc3-1b`) → di array `steps` Sesi 3, sisipkan **setelah** step `"vc3-1"` dan **sebelum** step `"vc3-2"`.
3. **BLOK C** (3 step, id `vc4-4a`, `vc4-4b`, `vc4-4c`) → di array `steps` Sesi 4, sisipkan **setelah** step `"vc4-4"` dan **sebelum** step `"vc4-5"`.
4. **BLOK D** (2 step, id `vc5-3a` dan `vc5-3b`) → di array `steps` Sesi 5, sisipkan **setelah** step `"vc5-3"` dan **sebelum** step `"vc5-4"`.
5. **BLOK E** (satu objek sesi utuh, `sesiNumber: 6`) → tambahkan sebagai elemen baru di array `vibeCodingMateri`, **setelah** objek Sesi 5, sebelum penutup `];`.
