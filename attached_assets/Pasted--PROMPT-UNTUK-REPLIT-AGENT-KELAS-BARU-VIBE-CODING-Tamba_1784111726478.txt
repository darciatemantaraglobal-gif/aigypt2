# PROMPT UNTUK REPLIT AGENT — KELAS BARU "VIBE CODING"

Tambahkan satu kelas baru ke platform AIGYPT bernama **"Vibe Coding: Dari Masalah Jadi Aplikasi"** dengan id `vibe-coding`. Kelas ini berisi 4 sesi materi interaktif. File konten lengkapnya saya lampirkan sebagai `vibeCoding.ts` — **gunakan file itu apa adanya, jangan menulis ulang atau meringkas isinya.**

Arsitektur konten multi-kelas sudah ada di project ini (registry `materiByKelas`, route dinamis `/kelas/:kelasId/materi/:sesi`). Ikuti pola yang sudah dipakai kelas `fundamental-ai`. Jangan membuat route baru, jangan membuat komponen renderer baru.

## LANGKAH 5 — Verifikasi (wajib, jangan dilewati)

1. `npm run build` (atau typecheck) harus lolos tanpa error TypeScript.
2. Buka `/kelas` — kartu "Vibe Coding: Dari Masalah Jadi Aplikasi" muncul dengan badge status `new`, gradient hijau emerald, dan aksen `#34D399`.
3. Buka `/kelas/vibe-coding` — halaman detail menampilkan 4 sesi dari `sessionsByKelas`.
4. Buka `/kelas/vibe-coding/materi/sesi-1` sampai `sesi-4` — semua sesi ter-render, termasuk blok `bigIdea`, `timeline`, `table`, `cards`, `flow`, `prompts`, dan `quiz` interaktif (klik jawaban → muncul umpan balik).
5. Pastikan kuis di Sesi 2 dan Sesi 4 bisa diklik dan menampilkan penjelasan `why`.
6. Pastikan progress tracking jalan: selesaikan sesi-1 dengan login member, cek progress tersimpan dengan `kelasId: "vibe-coding"` (jangan bercampur dengan progress kelas lain).
7. Cek tampilan mobile: kartu kelas, halaman detail, dan halaman materi nyaman di layar HP.
