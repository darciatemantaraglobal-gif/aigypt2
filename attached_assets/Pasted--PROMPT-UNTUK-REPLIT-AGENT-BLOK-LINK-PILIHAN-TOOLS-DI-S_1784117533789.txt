# PROMPT UNTUK REPLIT AGENT — BLOK LINK + PILIHAN TOOLS DI SESI 2 VIBE CODING

Kelas `vibe-coding` sudah live dengan 5 sesi. Tugasmu dua hal:

**A.** Menambahkan blok konten baru bertipe `links` ke sistem materi: daftar tautan eksternal yang bisa diklik, dengan penanda "Rekomendasi". Ini blok opsional, mengikuti pola blok visual yang sudah ada (`bigIdea`, `timeline`, `matrix`, `flow`) sehingga TIDAK mengubah konten atau step lama manapun.

**B.** Menyisipkan 3 step baru ke Sesi 2 kelas vibe-coding ("Kenalan Sama Dapurnya") yang memakai blok `links` itu: pilihan tempat deploy, pilihan database, pilihan backend, lengkap dengan rekomendasi.

## LANGKAH 1 — Tambah tipe `LinkItem` di `artifacts/aigypt/src/lib/materiContent.ts`

Di bagian blok visual (dekat `BigIdea`, `TimelineItem`, dst), tambahkan:

```ts
/** Daftar tautan eksternal yang bisa diklik, dengan penanda rekomendasi. */
export interface LinkItem {
  label: string;
  url: string;
  desc?: string;
  recommended?: boolean;
}
```

Lalu di `interface MateriStep`, tambahkan satu field opsional (letakkan setelah `flow?`):

```ts
links?: LinkItem[];
```

## LANGKAH 2 — Tambah renderer blok `links` di `artifacts/aigypt/src/pages/materi/index.tsx`

Di komponen yang merender `MateriStep` (tempat blok `flow`, `matrix`, `cards`, `table` dirender), tambahkan render untuk `step.links` dengan perilaku:

- Render sebagai daftar kartu vertikal (satu kolom, full width, nyaman di HP).
- Setiap kartu adalah `<a href={item.url} target="_blank" rel="noopener noreferrer">` — SELURUH kartu bisa diklik, bukan cuma teksnya.
- Isi kartu: `label` sebagai judul tebal, `desc` sebagai teks kecil di bawahnya (muted), dan ikon panah keluar (external link, inline SVG kecil) di kanan atas kartu sebagai penanda link keluar.
- Jika `recommended: true`: tampilkan badge kecil bertuliskan "Rekomendasi" dengan aksen ungu (#A855F7) di samping label, dan beri border kartu warna aksen ungu tipis supaya menonjol dari kartu lain.
- Styling mengikuti design system yang ada: latar kartu gelap (senada kartu-kartu lain di halaman materi), sudut membulat, hover state halus (border/glow menguat), transisi lembut. Jangan memperkenalkan warna atau font baru.
- Posisi render: setelah `content`, berdampingan wajar dengan blok lain (kalau step punya `content` + `links` + `note`, urutannya: content → links → note).
- Blok ini opsional: step lama tanpa `links` tidak boleh berubah tampilannya sama sekali.
